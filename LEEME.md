# Granja Ecológica UNIMINUTO

Sitio web académico para presentar los espacios, proyectos, fotografías y mapa de la Granja Ecológica UNIMINUTO. Está elaborado con HTML, CSS y JavaScript básico.

## Estructura

- `index.html`: inicio del sitio.
- `css/estilos.css`: estilos compartidos.
- `js/script.js`: menú y otras interacciones generales.
- `js/mapa.js`: interacciones del mapa.
- `modulos/`: páginas independientes de cada módulo: Espacios, Fotos, Mapa, Proyectos y Sobre la granja.
- `sources/`: fotografías, iconos y recursos del mapa.

## Abrir el sitio

Abre `index.html` en un navegador. Para editarlo, abre esta carpeta completa en Visual Studio Code.

## Fotos

Guarda las fotografías en `sources/fotos/fotos/`. Desde `modulos/fotos/fotos.html`, las imágenes se enlazan con rutas como `../../sources/fotos/fotos/nombre-de-la-foto.jpg`.

## Trabajo en equipo con GitHub

1. Cada integrante clona el repositorio una sola vez.
2. Antes de empezar, actualiza su copia con los cambios de `main`.
3. Crea una rama para su tarea, por ejemplo `fotos-galeria`.
4. Guarda cambios con commits pequeños y claros, y súbelos a GitHub.
5. Abre una solicitud de cambios (pull request) para revisar e integrar el trabajo a `main`.

Eviten trabajar directamente sobre `main`; así pueden revisar los cambios y reducir conflictos.
